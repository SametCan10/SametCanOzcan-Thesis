# Evaluating Nudging Strategies for Debiasing Job Recommendation Lists

MSc thesis — Data Science for Decision Making, Maastricht University

## Overview

A preregistered between-subjects online experiment (N = 174, recruited via 
Prolific) examining whether reflective nudges and automatic nudges can reduce 
gender bias and automation bias in AI assisted hiring decisions. Bias was 
measured using Mean Discounted Gain at cutoff 3 (MDG@3), a ranking sensitive 
metric capturing selection quality relative to an objective qualification standard.

## Data

Study data collected via Prolific. Dataset will be shown at DataverseNL.
